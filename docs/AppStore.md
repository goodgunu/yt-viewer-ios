# App Store 用コピー

審査へ出すバイナリは **Store** スキームだけです。Personal はサイドロード用で、説明文にもスクリーンショットにも出しません。

公開文は、特定の動画サービスの名前を出さない書き方にしています。

## 名前

Viewer

## サブタイトル

ページを開いて、その場で再生

## プロモーション用テキスト

アドレスを入れると、そのページをアプリの中で開きます。同梱のコンテンツフィルタが、広告枠の読み込みを抑えます。

## 説明

Viewer は、iPhone の中で動画サイトを見るためのブラウザです。アドレスを入力すると、そのページをアプリ内の画面で表示します。再生はページの中で続き、別のプレイヤーアプリへ移る必要はありません。

ページを読み込む前に、アプリへ同梱したコンテンツフィルタが働きます。広告配信用のリクエストと、ページ内の広告枠を抑えるためのルールはアプリの中にあり、追加のアカウントは要りません。

できること

- アドレス欄からページを開く
- アプリ内でのインライン再生
- 同梱のコンテンツフィルタ

この App Store 版に、動画ファイルの保存機能は含まれません。

## キーワード

動画,ブラウザ,プレーヤー,フィルタ,再生

商標や、特定サービスの名前は入れない。

## カテゴリ

エンターテインメント

## 年齢区分

17+ を推奨。ユーザーが指定したウェブページを、制限なく表示するため。

## スクリーンショットの文言

1. アドレスを入れて、そのまま開く
2. ページの動画は、この画面で再生
3. 同梱のフィルタで、表示をすっきり

### 撮影メモ

- **Store** スキームで撮る。ダウンロードのボタンと進捗は、このビルドに存在しない
- 6.7 インチと 6.1 インチを用意する
- 空の状態、再生中、設定、の 3 枚
- 特定サービスのロゴや商標が画面の主役にならないページを使う。自前のサンプルページでもよい
- ステータスバーは実機のキャプチャのままにする

## 審査メモ

日本語:

Viewer は単一画面のアプリ内ブラウザです。ユーザーが入力した URL を WKWebView で表示し、同梱のコンテンツルールとドキュメント末尾のユーザースクリプトで広告枠を抑えます。App Store 版に動画ファイルの保存、ログイン、課金はありません。フィルタのコンパイルに失敗しても、ページ表示自体は続きます。

English:

Viewer is a single-screen in-app browser. It loads a URL the user types into a WKWebView, and applies a bundled content-rule list plus a document-end user script that suppresses ad slots. The App Store binary does not save video files, and it has no account or purchase flow. If the content rules fail to compile, browsing still works.

## プライバシー

- アカウントは作らない
- トラッキングはしない（`NSPrivacyTracking` は false）
- 通信は、ユーザーが開いたページと、そのページが読むリソースだけ
- `PrivacyInfo.xcprivacy` を同梱。UserDefaults はアプリ自身の設定の保存（CA92.1）。Store 版はサーバー URL を保存しない
- サポート URL は用意していない。審査フォームでは空欄か、公開できるページを別に用意する

## 書き出し

1. スキーム **Store** を選ぶ
2. Any iOS Device で Archive
3. Organizer から App Store Connect へアップロード
4. スクリーンショットに Personal ビルドが写っていないことを確認する
